## Ejecutar en local

1. Clona el repositorio:

   git clone https://github.com/CamilaSalazar851/Portafolio.git

2. Entra al directorio:

   cd Portafolio

3. Abre `index.html` en tu navegador o levanta un servidor local. Por ejemplo, con Python:

   python -m http.server 8000

   Luego abre: http://localhost:8000

Si el proyecto usa Node y dependencias:

   npm install
   npm run dev
   # o
   npm start

## Despliegue

Puedes publicar fácilmente con GitHub Pages:
1. Ve a Settings → Pages en el repositorio.
2. Selecciona la rama `main` (o la rama por defecto) y la carpeta `/ (root)`.
3. Guarda y espera a que la página se publique.

Alternativas: Netlify, Vercel (conectar el repositorio y seguir el flujo de despliegue).
